## How to run the loop

Provider keys: source the sibling `dns-remote-agent/.env` in the shell (or a local
gitignored `.env`). Do not commit keys. Unset host-git / Linear tokens before the
worker starts.

```bash
docker compose up postgres -d
npm run build
npm run build:web
npm run build:pi-agent-image
bash scripts/live-board-e2e.sh
```
